# PULSE™ — промо-сайт маркетингової агенції

Вигадана агенція (структура натхненна upliftagency.com.ua, усе інше — власне: назва, ціни, копірайт).
Односторінковий сайт на 4 екрани з «живим» моушн-дизайном — без жодного відео, уся анімація реагує на курсор і скрол.

## Як відкрити

Варіант 1 (найпростіше): просто відкрийте `index.html` подвійним кліком у Chrome/Edge.

Варіант 2 (локальний сервер):

```
python -m http.server 8321
# → http://127.0.0.1:8321
```

Зараз сервер уже запущений на `http://127.0.0.1:8321/index.html`.

## Що на сайті

1. **Hero** — кінетичний заголовок (літери розлітаються від курсора), canvas-сузір'я частинок, що тяжіє до курсора, паралакс-градієнти, лічильники статистики.
2. **Послуги + ціни** — 3 тарифи («Імпульс» 24 000 ₴, «Ритм» 39 000 ₴/міс, «Повний цикл» від 65 000 ₴/міс) + окремі послуги; 3D-тилт карток і glow, що стежить за курсором.
3. **Як працюємо** — 4 кроки + умова пілоту (−50% при недосягненні KPI).
4. **Контакти** — форма заявки (демо), контакти, футер.

## Елементи «оживання»

- Кастомний курсор: точка + кільце, що відстає; росте над посиланнями, стискається при кліку.
- Магнітні кнопки — тягнуться до курсора.
- Canvas-фон: частинки з'єднуються лініями і підтягуються до курсора (фіолетові лінії до курсора, жовті — між собою).
- Кінетична типографіка hero.
- Паралакс hero та градієнтних «блобів» від позиції миші.
- Бігуча строка послуг, scroll-reveal, прогрес-бар скролу, анімовані лічильники.
- Пульсуючий логотип, зерно-шум на фоні.

## Поведінка

- На тач-пристроях кастомний курсор вимикається, решта анімацій працює.
- `prefers-reduced-motion` — уся анімація вимикається.
- Файли: `index.html`, `style.css`, `script.js`. Залежності — лише Google Fonts (Unbounded + Space Grotesk).
